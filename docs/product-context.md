# isodo

供个人用户使用 Agent 完成开发和日常任务的沙箱工作空间产品。

## Language

**沙箱（Sandbox）**：用户拥有的隔离工作环境，包含持久文件、环境、Agent 和任务；每个用户可以拥有多个本地或云端沙箱。
_Avoid_：用 Session 或 Task 指代整个工作环境

**Agent**：在沙箱内执行工作的助手，例如 Claude Code、Codex、dsh 和 OpenCode。

**任务（Task）**：指定沙箱内的一次工作，包含对话、执行过程和产出。

**快照（Snapshot）**：沙箱文件和环境在特定时刻的保存版本，不包含运行中内存；上传后可用于在云端创建独立沙箱，新旧沙箱各自变化。

**凭证库（Credential Library）**：个人账号统一管理的服务连接与 Agent 配置集合，按沙箱授权并可撤销。

**服务连接（Service Connection）**：账号中可复用的外部服务访问配置，包含服务地址、协议和凭证；多个 Agent 配置可以引用同一服务连接。

**Agent 配置（Agent Configuration）**：供指定 Agent 使用的一组配置，引用服务连接，并描述该 Agent 使用的模型及配置文件。

**密钥占位符（Secret Placeholder）**：Agent 配置中代替真实密钥的标记；真实凭证由沙箱外的注入规则提供。

**安全连接（Secure Connection）**：指定沙箱获准使用某个外部服务的关系。持久规则属于账号凭证库，单次规则只属于当前沙箱；两者都通过沙箱外的注入代理使用密钥。

**持久注入规则（Persistent Injection）**：账号级保存的匹配与注入规则，跟随登录用户，可被多个沙箱引用。

**单次注入（One-off Injection）**：只在当前沙箱生效的规则，删除沙箱或规则后失效，不进入账号凭证库。

**用途模板（Template）**：为代码开发、日常助手或空白环境预先准备的沙箱起点。

**订阅套餐（Plan）**：账号权益等级 Free、Plus、Pro，主要区分云端计算资源、快照存储和保留数量，不包含模型额度。
