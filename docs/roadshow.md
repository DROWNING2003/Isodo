## 演示主线（约 5 分钟）

1. **工作空间**：说明沙箱是主体，任务、文件与连接属于沙箱；展示本地/云端入口。
2. **真实任务**：进入已准备的远程 CHV，选择已验证的模型连接，让 Codex 创建一个小程序并运行测试。
3. **产物与终端**：打开生成文件与测试输出，确认工作发生在 Guest。新标准沙箱内为 root，宿主权限不变。
4. **HTTP 服务**：用 Commands 或终端启动 3000 端口服务，展示公开预览，再切为 private，说明授权与撤销。
5. **工具和技能**：展示 MCP 收藏→连接→当前沙箱勾选→保存；使用 GitHub 只读或 DeepWiki 公共 MCP。展示已收藏 Skill 在新任务中加载。
6. **架构与边界**：简述 Control→Node→Guest、凭证留在沙箱外，以及停止保盘和运行身份隔离。

现场优先使用已实际验证的模型名与服务参数；OpenAI 兼容地址不保证支持 `service_tier=priority`。不要在路演前临时更换 Agent CLI、模板、模型档位或 OAuth 权限。

## 已知故障与恢复

- 工作台域名不匹配：先校验 Web 构建的预览域名和完整工作台模式，按[发布检查](web-preview-release-checklist.md)处理。
- MCP 502：检查 Node 实际命名空间中的 Broker DNS、TLS 和 hosts 私有挂载，再做 Guest 工具发现。
- T3 重载卡住：VM 可能仍 running。检查 app-link、Guest T3 PID 与代理初始化，避免直接重建工作盘；PR #40 的 pidfd 兜底是否在线上，以实际部署为准。
- 模型参数错误：检查供应方支持的模型和参数，不通过关闭沙箱鉴权处理模型服务错误。
