# 沙箱安全连接交互验证

问题：安全连接不是 chat 路由，旧侧栏因此将环境设为 null；没有 project/thread 上下文，新任务与文件按钮未绑定动作。

修复：按路由 sandbox ID 从全局连接目录恢复环境，使用记录的草稿/任务作为上下文。文件操作从配置页返回相应工作台；无现有任务时创建草稿后打开文件。

临时 Agent 新增沙箱级表单，复用现有模型发现与模板生成。临时规则采用独立 placeholder 条件，配置文件不包含真实 Key；数据进入已有加密 sandbox credential document，不进入 agents 全局列表。保存、编辑、撤销同时刷新该沙箱的模型快照与规则。

验证：3 个聚焦测试文件、16 项通过，覆盖安全连接页新任务与文件动作、勾选变化、右下角图标保存、临时 Agent 沙箱级保存、placeholder 写文件及临时注入条件。Web 类型检查通过；lint 无错误，状态同步 effect 有提示。没有执行桌面点击或真实中转站推理验证。
