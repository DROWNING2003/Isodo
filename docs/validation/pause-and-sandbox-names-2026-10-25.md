# 显式暂停与工作区名称

用户要求：显式断开时直接暂停沙箱，工作区选择器使用创建时的沙箱名称。

实现：侧栏与连接设置调用 pauseAndDisconnect，按所属运行时调用 stop，并等待 stopped/paused 后关闭 transport。普通导航与列表停止/删除后的 transport 清理不新增 stop。失败保留连接并反馈错误。使用现有停止/启动链路，保留磁盘，不承诺保存运行中的内存状态。

默认工作区标题通过现有 T3 project update 接口持久化为所属沙箱名称，兼容当前 `/workspace/project` 和旧路径。只更新默认 `isodo Sandbox` 标题，不覆盖用户自定义项目名称。已暂停且已配对的沙箱进入启动界面；启动成功后更新列表缓存再恢复连接。

验证：5 个聚焦前端测试文件、26 项通过。覆盖本地/云端暂停目标、等待停止、暂停失败不断开、其他沙箱不受影响、已有任务保留、不同沙箱名称隔离、用户项目名称保留，以及暂停后进入启动界面。没有为验证而实际停止用户正在运行的沙箱，也没有桌面点击验证。
