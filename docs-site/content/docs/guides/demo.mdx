# 演示与能力边界

当前支持在远程 CHV 沙箱中使用真实 Agent、文件 API、命令执行、HTTP 服务预览、MCP 和 Skill。Electron 同时提供本地 Lima 入口；本地市场绑定能力与远程并不完全相同。

## 建议的五分钟流程

1. 创建专用云端沙箱，等待 running；首次镜像下载可能增加冷启动耗时。
2. 选择已验证的模型连接，进入工作台并新建任务，展示实际生成与文件结果。
3. 展示文件查询、写入及终端；公开 API 可独立执行有界命令。
4. 在 Guest 启动 Python HTTP 服务，打开端口预览；演示 public 匿名访问和 private 拒绝匿名访问。
5. 展示已明确授权的 GitHub 只读 MCP 或公共自定义 MCP 的一次工具调用。
6. 选择已收藏的 Skill，统一保存配置，在新任务验证指令加载。

不要将“已连接”或“已应用”作为 Agent 已完成工具调用的证明。Notion 的 OAuth 和工具发现已有验证，私有页面完整任务仍需有权限的测试页面单独验收。

## 已记录的真实验证

- 本地和远程新 root 模板均完成 Guest UID 0、系统目录写入与实际软件包安装/卸载测试，专用测试资源已删除。
- CHV 的 Files、Commands、HTTP Preview、GitHub / 自定义 MCP 和 Skill 已有隔离沙箱验收记录。
- 详细 Sandbox ID、部署快照及未验证项保存在仓库 `docs/current-status.md`；历史逐次记录通过 Git 查看。

## 演示前确认

确认 VPN / 域名解析、API 健康、实际工作台连接、模型请求、MCP tools 调用和服务预览。代码 main、线上二进制、Web 构建与文档站分别核对，不能用首页 200 代替验收。

产品级跨端快照、商业套餐、独立公开 PTY/Processes API 和完整跨节点自动恢复不作为已完成能力展示。T3 退出超时兜底已合并但尚未部署，不能把源代码修复当作线上修复。

当前路演检查与交付步骤见仓库 `docs/roadshow.md`。页面内容更新本身不会部署服务。
