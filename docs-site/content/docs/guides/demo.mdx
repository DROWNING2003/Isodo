# 演示与当前能力

本页按 2026-10-25 至 26 日的实机结果描述 MVP。录屏主线是：**同一个 Isodo App → 云端沙箱 → Agent 工作台 → 真实模型任务 → 文件与测试结果**。

## 已实测

| 环节 | 结果 |
| --- | --- |
| 云端创建 | App 经本机 Control、SSH/mTLS 和独立 Node 创建 CHV，Guest Ready |
| Agent 工作台 | Gateway Cookie bootstrap、配对与任务连接通过 |
| 模型任务 | Codex 选择 gpt-6.1-sol，实际生成 Python 文件并运行两个 unittest |
| 凭证边界 | 宿主注入计数增加；Guest 认证文件只包含占位符 |
| 文件 | 零字节、文本、300KB 二进制往返摘要一致；禁止覆盖和目录边界拒绝通过 |
| 终端 | 修复 Guest devpts 挂载后，App 终端实际运行测试，UID/GID 为 1000 |
| 保盘恢复 | 原云端测试沙箱停止、启动后，原任务与文件可恢复 |
| 新工件探针 | 创建、工作台 HTTP、重启、停止、实际删除通过 |
| 本地 Lima | 同一 App 创建新沙箱、应用 Agent 配置并连接工作台通过；本轮不据此宣称完整本地模型回归完成 |

## 录屏流程（约 3–5 分钟）

1. 展示“我的沙箱”的本地 / 云端入口，说明工作区与模型连接由用户管理。
2. 选择云端 Ready 模板创建沙箱，并选择已有 Codex 配置。说明真实密钥保存在沙箱外，屏幕只展示脱敏配置。
3. 等待运行态，进入 Agent 工作台。首次下载模板可能较慢，可以剪去等待，但保留真实状态变化。
4. 选择已配置模型，发送下面的任务，展示实际生成过程。
5. 打开文件面板查看产物；打开终端执行测试，展示真实输出。
6. 返回列表，展示保盘停止 / 启动及重新进入工作台。结束时保留可运行的演示沙箱。

建议任务：

```text
在当前工作区创建 isodo_demo.py，包含一个统计单词数量的 Python 函数和两个 unittest。
实际运行测试，简要报告结果。不要读取或打印凭证、Token、环境变量或认证文件。
```

终端复核：

```bash
cd /workspace/project
python3 -m unittest -v isodo_demo.py
id
```

已有已完成任务可以用于展示最终产物；只有真实重新发送模型请求时，才把该段描述为实时生成。

## 演示边界

本轮真实模型任务验收的是 Codex。Claude CLI 已包含在云端基础镜像中，但不把安装视为完整模型任务验收。App 中的 Skill、MCP、快照、安全页以及商业套餐仍有未开放或未实现部分，录屏不将它们描述为已交付。

无网卡 CHV 通过 Vsock 出站代理访问模型。Lima 使用其本地运行环境；两种后端共用 App 业务接口，不意味着网络和内核实现相同。完整跨节点恢复、公开 SDK、通用 PTY/Commands API 和生产级安全认证均不属于本次 MVP 完成声明。
