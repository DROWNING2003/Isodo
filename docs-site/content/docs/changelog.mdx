# 更新记录

## 2026-11-03 · 运行时与开发者文档

- 新标准 Lima / CHV 模板默认 Guest root，支持系统依赖安装；既有沙箱保持原镜像和用户。
- 公开 Files 补齐 Stat、分页 ListDirectory、Remove 和 Move，保留工作区安全边界。
- Notion 接入元数据发现、DCR、PKCE 与只读工具白名单；不再提供 Supabase 官方目录项。
- T3 优雅退出卡住时的有界 pidfd 终止兜底已合并；当前 Node 尚未部署该补丁。
- 整理 README、当前能力、验收边界和路演检查；API 文案与在线调试器改为中文，协议字段保持不变。

## 2026-11-02 · Agent 与工具链路

- Commands API 提供有界非交互式 Guest 命令执行，独立 `sandboxes:execute` 权限。
- 通用 HTTP Preview 支持 HTTP、WebSocket、SSE，默认 public，可逐端口切换 private；管理端口禁止预览，T3 鉴权独立。
- GitHub 官方只读 MCP、公共自定义 HTTPS MCP 与 Skill 完成真实 CHV / Codex 调用验证。
- MCP / Skill 的收藏与沙箱授权分离，安全连接页统一保存选择。
- 出站环境准备前移至沙箱 Ready，API 驱动 Agent 不再依赖先打开工作台。

公开接口版本仍为 `0.1.0`。源码合并、线上部署、文档发布和打包验收分别记录；完整证据与限制见仓库 `docs/current-status.md`。
