# 为 Agent 构建安全的工作空间

Isodo 是面向个人用户的 AI Agent 安全工作空间。选择本地或云端沙箱，在同一个 App 中授权模型连接、打开 Agent 工作台、让 Agent 编写代码并查看文件与测试结果。

本地使用 Lima，云端使用 Cloud Hypervisor。Agent 在 Linux 虚拟机中运行，真实模型密钥由沙箱外的代理注入；沙箱中的配置文件使用占位符。

## 产品结构

| 区域 | 职责 |
| --- | --- |
| Isodo App | 统一 SandboxClient；本地 IPC、云端 HTTP 只在适配层区分 |
| Control | OAuth 会话、资源归属、生命周期意图、数据库 outbox 与 Node mTLS |
| Node Runtime | Lima / CHV 生命周期、Guest RPC、文件转发、Vsock 与凭证代理 |
| Guest / Agent 工作台 | 新模板 Guest root 执行、工作区文件、任务、模型调用和终端 |
| 模板存储 | SeaweedFS S3，按 manifest digest 校验并缓存工件 |

远程 CHV 已完成专用沙箱中的 Commands、HTTP 端口预览、GitHub / 自定义 MCP，以及 Skill 的 Web 工作台真实验收。可继续阅读 [GitHub 与自定义 MCP](/docs/guides/github-mcp) 和 [Skill 市场](/docs/guides/skills)。这些结果不等同于所有 Agent、本地 Lima 或完整 Electron 桌面端均已验收；App 快照流转、完整跨节点恢复和商业套餐仍有独立的实现及验收边界。
