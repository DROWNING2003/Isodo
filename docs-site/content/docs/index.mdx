# 为 Agent 构建安全的工作空间

Isodo 为 AI Agent 和自动化任务提供按需创建的沙箱。每个沙箱拥有独立的运行环境；控制面负责身份认证、资源归属和生命周期管理，运行时负责隔离执行。

## 从这里开始

- [快速开始](/docs/guides/quickstart)：配置本地服务并发起第一个 API 请求。
- [身份认证](/docs/guides/authentication)：了解网页登录会话、Casdoor Bearer Token 和 API Key。
- [Sandbox 概念](/docs/concepts/sandbox)：了解 Sandbox 的状态、归属和隔离边界。
- [API Reference](/docs/api-reference)：浏览由公开 OpenAPI 契约生成的接口文档。

## 产品结构

| 区域 | 职责 |
| --- | --- |
| 控制面 | 用户认证、API Key 管理、Sandbox API 和资源归属校验 |
| Node Runtime | 在节点上协调隔离运行时，并向控制面报告状态 |
| Guest Agent | 在沙箱内执行命令、管理文件与终端会话 |
| 文档与 SDK | 从公开 API 契约生成接口参考，并为 SDK 提供稳定边界 |

各组件按产品目标设计；具体后端、部署方式和能力以对应指南与 API 契约为准。
