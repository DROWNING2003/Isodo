# 模板与持久存储

模板是元数据；Build 固定镜像工件与校验信息；Tag 指向 Ready Build。创建沙箱固定到具体 Build，不随 Tag 后续变化自动更换镜像。

Node 校验 manifest 与工件摘要，从 S3 兼容存储获取系统工件并缓存。当前演示使用 SeaweedFS 的 S3 接口；沙箱工作盘独立持久化，Stop/Start 保留文件，Delete 在确认 VM 和磁盘清理后完成。

新标准模板使用 root:0:0，旧 isodo:1000:1000 模板继续按原身份运行，混合用户信息不合法。升级服务不会自动迁移已有沙箱。构建和验证流程见[Guest root](../docs/guest-root-runtime.md)及 `images/`。

内部 warm restore / snapshot 模板属于运行时优化，不等于已交付用户可管理的跨端快照产品。公开模板构建登记接口与管理员系统镜像发布也应分开描述；任务登记成功不能作为工件构建完成的证据。

上传权限、Node 读取权限和删除权限需分别配置。工件校验、失败清理、引用与生命周期约束不能为演示绕过。
